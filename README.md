# Crypto Market Bot v3.2 (Binance Spot → Telegram)

نظام متعدد القنوات. كل قناة لها عملاتها ومواعيدها وتنبيهاتها، وكلها تُدار من لوحة Pages.

## كيف يشتغل (نفس طريقة النسخة القديمة الشغالة)
- **Worker + كرون `* * * * *`** كل دقيقة. الكود يقرر شنو ينشر. **بدون Durable Objects.**
- الإعدادات والتوكن المحفوظ من اللوحة بـ **KV** (يُكتب فقط عند الحفظ من اللوحة أو عند وصول سعر لمستوى تنبيه).
- السجل يُكتب لـ KV كل 10 دقائق كحد أقصى (أو فوراً عند أول فشل) لحماية حد KV المجاني.
- حالة الجدولة وسجل الأسعار لتنبيه الحركة السريعة بالذاكرة (مثل القديم): إذا تغيّر الـ isolate يعيد بناء السجل خلال دقائق.
- طلب واحد لـ Binance لكل نوع بيانات لكل القنوات (حتى 100 زوج/طلب).

## الإعداد (مرة وحدة)
Secrets في Worker:
- `TELEGRAM_BOT_TOKEN`
- `ADMIN_KEY`
- `TELEGRAM_CHAT_ID` (اختياري: يُستعمل فقط لتعبئة أول قناة عند الترحيل)

## إضافة قناة
1. أضف البوت أدمن بالقناة (صلاحية Post Messages).
2. من اللوحة ← القنوات ← إضافة قناة. اكتب `@username` أو رقم `-100...` للقنوات الخاصة.
3. اضغط **تجربة اتصال** ثم **حفظ**. تبدأ الأسعار فوراً، والتقارير في مواعيدها.

## الأنواع
أسعار (كل N دقيقة) · تحليل ساعة · تقرير 4 ساعات (+RSI/MA اختياري) · يومي · أسبوعي · تنبيه حركة سريعة · تنبيه مستوى سعر.
المواعيد بتوقيت القناة (فرق التوقيت يُختار من اللوحة).

## ملاحظات
- لا تضع Bot Token في GitHub أو اللوحة.
- مراقبة الأعطال: تبويب الحالة، وتنبيه تيليغرام على chat id الخاص بك (تبويب عام).

## الجديد بالنسخة 3: تبويب «الاتصال» (كل شي من اللوحة)
- **روابط Binance**: إضافة/حذف/تعطيل/ترتيب الروابط، ومهلة كل رابط. البوت يتذكر آخر رابط نجح ويبدأ به.
- **فحص كل الروابط**: يبين أي رابط يشتغل وأي رابط محجوب (HTTP 451/403 = حظر منطقة).
- **رابط وسيط (Proxy)**: إذا كل روابط Binance محجوبة من سيرفرات Cloudflare، أضف رابط وسيط خاص بك (يعيد توجيه /api/v3/* إلى Binance) كأول رابط.
- **توكن تيليغرام**: يتغير من اللوحة بعد التحقق منه مع تيليغرام، ويُحفظ داخل الـ Worker ولا يرجع للوحة (يظهر مخفي).
- تبويب الحالة يعرض آخر اتصال ناجح/فاشل مع Binance وسبب الفشل.

> هذي النسخة تحتاج نشر واحد (`wrangler deploy` + رفع مجلد dashboard). بعدها كل تعديل على الروابط والتوكن والقنوات من اللوحة.

## الجديد بالنسخة 3.2
- **منصات متعددة**: Binance, Bybit, OKX, KuCoin, Bitget, Gate.io, MEXC. كل قناة تختار منصتها أو «تلقائي». إذا فشلت منصة ينتقل للتالية ويبلغ الأدمن. تبويب الاتصال فيه ترتيب المنصات وزر اختبار يعرض قراءة BTC الفعلية.
- **قنوات سعر عملة واحدة**: زر «+ قناة سعر عملة واحدة». تنشر رسالة قصيرة مثل `$5677.77666` كل 3 دقائق (قابل للتغيير) وقالبها قابل للتعديل: `{price}` `{symbol}` `{change}`.
- **إشعارات الأدمن (إنجليزي)**: فشل النشر، تبديل المنصة والتعافي، تحديث إعدادات من اللوحة، وتشغيل نسخة جديدة بعد النشر. (لازم تسوي Start لبوتك وتضبط Admin chat ID.)
- تقارير الساعة/4 ساعات/اليومي/الأسبوعي ومؤشرات RSI تعتمد Binance فقط. الأسعار والتنبيهات تشتغل على كل المنصات.

## تبويب «الشبكة» (منشور مثبت موحّد)
نص + أزرار روابط، يُنشر ويُثبّت بالقنوات المختارة بضغطة وحدة. إعادة الضغط بعد التعديل تعدّل المنشور القديم بدل التكرار. البوت لازم أدمن بكل قناة مع صلاحية Pin messages.

## تبويب «نشر» (منشور حر لمرة وحدة)
نص + أزرار (زر قناة أو رابط مخصص، ترتيب وحذف وتعديل) + خيارات: تثبيت، بدون إشعار، قناة معينة أو الكل. محرر الأزرار نفسه مستعمل بتبويب «الشبكة».
